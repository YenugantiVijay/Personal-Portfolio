# 🚀 Vijay Kumar Yenuganti — Personal Portfolio

A smooth, animated personal portfolio website built with plain **HTML, CSS and JavaScript** — no frameworks, no build step. 🎨✨

From spreadsheets 📊 to code 💻 — this site tells the story of my journey from accounts and warehouse management to front-end development.

## ✨ Features

- 🌊 Smooth scrolling with a scroll progress bar
- ⌨️ Typing role animation in the hero section
- 🔢 Animated stat counters
- 🎞️ Scroll-reveal animations on every section
- 🏷️ Skills ticker that scrolls across the page
- 🃏 3D tilt effect on cards
- 🌗 Light / dark mode with sun & moon icons (remembers your choice)
- 📱 Fully responsive for mobile, tablet and desktop
- ♿ Respects reduced-motion settings
