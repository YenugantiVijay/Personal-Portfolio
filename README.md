# Personal Portfolio

My personal portfolio website, built with plain HTML, CSS and JavaScript. No frameworks, no build step.

**Live site:** https://vijaykumar-yenuganti.github.io/Personal-Portfolio/

## About

I'm Vijay Kumar Yenuganti, a front-end developer at Mindminds Pvt. Ltd. I started my career in accounts and warehouse operations, so I like building interfaces that are tidy, practical and made for real work. This site covers who I am, my journey, my skills and my projects.

## Features

- Single-page layout with smooth section navigation (About, Journey, Skills, Strengths, Work, Contact)
- Light and dark theme toggle that remembers your choice
- Scroll progress bar and scroll-reveal animations
- Typing animation for role titles in the hero section
- Animated stat counters and a scrolling skills marquee
- Interactive glow effect in the hero and tilt effect on cards
- Active nav link highlighting based on the section on screen
- Fully responsive for mobile, tablet and desktop

## Tech Stack

- **HTML5** for structure
- **CSS3** for styling, layout and theming (CSS variables)
- **Vanilla JavaScript** for interactivity and animations
- **Google Fonts** (Space Grotesk and JetBrains Mono)

## Project Structure

## Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/vijaykumar-yenuganti/Personal-Portfolio.git
   ```
2. Go into the folder
   ```bash
   cd Personal-Portfolio
   ```
3. Open `index.html` in your browser, or use a local server such as the VS Code Live Server extension.

## Deployment

The site is hosted on GitHub Pages:

1. Go to **Settings → Pages** in this repository
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select the `main` branch and the `/ (root)` folder, then save

## Customize

- Edit text and sections in `index.html`
- Change colors, fonts and spacing in `style.css`
- Update the skills marquee and role titles in `script.js`
